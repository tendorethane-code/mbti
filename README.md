# Tes Kepribadian Lengkap

Tes kepribadian 184 soal dalam 4 modul: MBTI 4 huruf + identitas (Assertive/Turbulent), 20 facet Step II, Big Five 30 facet, dan 8 cognitive functions. Hasilnya keluar otomatis setelah modul selesai.

- Progres kesimpan di browser (localStorage), jadi bisa dicicil.
- Hasil bisa di-download sebagai kartu PNG, disimpan sebagai PDF, atau disimpan sebagai file jawaban `.json` yang bisa dibuka lagi.
- Semua jalan di browser. Nggak ada jawaban yang dikirim ke server.

Live: https://tendorethane-code.github.io/mbti/

Catatan: soal-soal ini belum divalidasi secara ilmiah. MBTI dan cognitive functions dukungan risetnya lemah; Big Five paling kuat.
